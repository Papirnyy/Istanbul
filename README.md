# Никита и Полина — Стамбул

Фотоальбом о первой совместной поездке в Стамбул.

**Сайт:** https://papirnyy.github.io/Istanbul/

В галерее 45 фотографий: поймайте сердечко, чтобы открыть кадр, а затем листайте альбом кнопками или стрелками клавиатуры. Карточки и просмотр фотографий реагируют на движение курсора с 3D-эффектом. Сайт работает как статическая страница без сборки и дополнительных зависимостей.
